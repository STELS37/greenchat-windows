# GreenChat asset licensing

Unless a file or directory contains a more specific notice, the original GreenChat visual and audio assets distributed in this repository are part of the GreenChat Program and are licensed under **GNU AGPL-3.0-or-later** together with the client source.

This includes:

- GreenChat SVG brand artwork and favicons in `clients/web/public`;
- generated PNG, ICO and ICNS application icons in `clients/desktop/src-tauri/icons`;
- the GreenChat incoming-call and outgoing-call sounds in `clients/web/public/assets`.

For the icons, the SVG artwork is the preferred form for modification and the raster files are generated or packaged derivatives. For the two call sounds, the tracked audio files are the maintained source assets used by the application.
