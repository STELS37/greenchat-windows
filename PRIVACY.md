# Privacy statement

GreenChat Desktop is a client application. It connects to the GreenChat service selected at build time and processes the information required for messaging, calls, contacts, files, account security and optional financial interfaces exposed by that service.

The normative client-facing privacy text is maintained in [`docs/legal/privacy.md`](docs/legal/privacy.md) and is embedded into the application during the build. The hosted policy is available through the GreenChat service at `https://greenchat.globalsystem.cc/privacy/`.

## Local data

The desktop application may store:

- interface preferences and non-sensitive cache data;
- encrypted local client state;
- a refresh credential through the operating system's protected credential store;
- diagnostic information generated by the application;
- downloaded files explicitly requested by the user.

The Windows client does not intentionally commit credentials, private keys or personal data to this source repository or to GitHub Actions artifacts.

## Permissions

Camera, microphone, notifications, file access, screen sharing and startup behavior are used only after the corresponding user action or operating-system permission. GreenChat Desktop does not silently enable these permissions merely because the user signed in.

## Security reports

Do not include personal data or live credentials in a public issue. Use the private process in [SECURITY.md](SECURITY.md).
