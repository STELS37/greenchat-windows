The messenger that never asks for your phone number

Green Chat is a fast, honest messenger: an account is just a @username and a password, delivery recovers after disconnects, and privacy controls remain understandable.

Open Green Chat

No phone number required

A @username and password are enough to register. A number and SMS are optional; phone and e-mail values are never shown to other users.

Messages survive disconnects

Outgoing work waits for connectivity and resumes when the network returns, while missed events are recovered from the server cursor without duplicates.

Undo before the operation commits

A send or deletion can be cancelled for five seconds while the operation is still held in the local queue.

Choose the server before sign-in

The server address is selected explicitly before authentication. The client sends application traffic only to that chosen host, and changing it remains a deliberate user action.

Profile privacy controls

Phone and e-mail values are not published in the profile. The app provides visibility settings, contact controls, and blocking for unwanted users.
