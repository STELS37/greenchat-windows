# Maintainers and release roles

## Current maintainers

| GitHub account | Author | Reviewer | SignPath approver |
|---|---:|---:|---:|
| `@STELS37` | yes | yes | pending SignPath enrollment |

No person may review their own pull request or approve a signing request containing unreviewed changes authored solely by that same person. Before signed public releases begin, at least one additional reviewer/approver must be enrolled so that author and approval duties can be separated in practice.

All accounts with write, review or signing privileges must use multi-factor authentication. Access is reviewed when maintainers join, leave or change responsibilities.
